# LAST 72 HOURS — SURVIVE THE JOURNEY: Handoff

เกม point-and-click survival สำหรับ NASA Space Apps Thailand
นักบินอวกาศมีเวลา 72 ชั่วโมงในเกมเพื่อซ่อมยานให้ทันก่อนหน้าต่างการกระโดด (Jump window)

## เริ่มต้นใช้งาน

- Unity **6000.3.26f1**, URP 2D, Input System 1.20
- Clone repo แล้วเปิดโฟลเดอร์ `Naja` ใน Unity Hub
- เปิด scene `Assets/Scenes/SampleScene.unity` แล้วกด Play ได้เลย
- UI ทั้งหมดสร้างด้วยโค้ด (`GameUI` สร้างตัวเองอัตโนมัติ) ไม่ต้องลากของใน scene
- ห้ามแก้ scene เดียวกันพร้อมกันหลายคน กด Fetch/Pull ก่อนเริ่มงานทุกครั้ง

## ระบบเกม

- **เวลา:** นับถอยหลัง 72:00:00 การเดินและเปลี่ยนห้องไม่เสียเวลา การซ่อมเสียเวลาตามตารางของ GameModel
- **การซ่อม:** แต่ละอย่างมีมินิเกม 5–20 วินาที สำเร็จ = เสียเวลาปกติ พลาด = +30 นาที แล้วลองใหม่ได้ ทำแบบ Perfect ได้โบนัสเล็กน้อย
- **ทรัพยากร:** O2, ไฟ, เชื้อเพลิง, ความหิว, ความเหนื่อย
- **ห้อง:** 4 ห้องหลัก (Quarters, Command, Life Support, Engineering) และ 4 ห้องใน (Cabin, Comms Room, Crawlspace, Parts Storage) เข้าผ่านช่องทางบนผนังหลัง
- **Lockdown:** ถ้า Engineering ถูกล็อก ผู้เล่นที่อยู่ใน Engineering หรือ Parts Storage จะถูกย้ายไป Command
- **รหัส Security Override:** 4719 (อยู่ใน voice log ของวิศวกร Mali)

## ห้อง 2.5D

- ทุกห้องเป็นกล่องเปอร์สเปกทีฟมองจากด้านหน้า พื้นเป็นสี่เหลี่ยมคางหมู
- เดินด้วย WASD หรือลูกศร (8 ทิศ) หรือคลิกพื้น ตัวละครจะเดินอ้อมเฟอร์นิเจอร์เอง
- ยิ่งใกล้จอยิ่งตัวใหญ่ (×1.25 ด้านหน้า เหลือ ×0.52–0.72 ด้านหลังตามห้อง)
- เดินชนประตู: A ซ้าย, D ขวา, W ช่องทางบนผนังหลังเข้าห้องใน, S ที่ขอบล่างออกจากห้องใน กด E ก็ได้
- ดับเบิลคลิกวัตถุ ประตู หรือพื้น = ไปถึงทันที
- Esc ปิดหน้าต่าง → วางไอเทมที่ถือ → เปิดเมนู pause
- ของที่ใช้ได้มีเครื่องหมาย ? / ! / ✓ ส่วนของตกแต่ง (`deco_*`) ใช้ไม่ได้ แต่ขวางทางเดิน
- **ย้ายวัตถุ:** แก้บรรทัด `S(id, kind, x, ความลึก, กว้าง, สูง, footprintDepth, lift)` ใน `Stage25D.Init()`

## งานศิลป์ (สำหรับเพื่อน)

เกมตอนนี้เป็น graybox ทั้งหมด รูปแทนกล่องสีเทาได้โดยไม่ต้องแก้โค้ด วางไฟล์ PNG ใน `Assets/Resources/Art` ตามชื่อและขนาดที่ระบุใน **`docs/ART_SLOTS.md`**
(ห้อง `room_<ชื่อ>.png`, วัตถุ `obj_<id>.png`, ของตกแต่ง `deco_*.png`, ภาพซูม `closeup_<id>.png`, ตัวละคร `astronaut.png`, เคอร์เซอร์ `cursor_<kind>.png`)
ภาพ graybox แต่ละห้องอยู่ใน `Naja/Captures/8x_*.png` ใช้เป็นแบบวาดทับได้
เอกสารอ้างอิง UX: `docs/UI_LAYOUT.md`, ภาพเกมอ้างอิง `docs/ref_*.jpg` (ใช้อ้างอิงเท่านั้น ห้ามเอาไปใช้ในเกม)

## ทดสอบแล้ว / ยังไม่ได้ทดสอบ

ทดสอบแล้ว (ผ่านสคริปต์ใน Play mode และจำลอง dotnet):
- เดินด้วยปุ่มและคลิก, เดินอ้อมเฟอร์นิเจอร์, เดินชนประตู, ย้ายห้อง, เข้า-ออกห้องใน, หน้าต่างวัตถุ, lockdown, ตรรกะเวลา/ending

ยังไม่ได้ทดสอบ:
- ความรู้สึกเล่นจริงด้วยคีย์บอร์ดและเมาส์ (ความเร็วเดิน)
- เคอร์เซอร์บนหน้าจอจริง
- การกระแทกประตู Engineering ที่ล็อกด้วยการเดินชน (โค้ดไม่เปลี่ยน แต่ยังไม่ได้ลอง)
- ไม่มี build .exe

## ปัญหาที่รู้อยู่

- ป้าย [E] ทับฉลากของประตูบางบาน
- ข้อความแจ้งเตือนมุมขวาบนทับผนังขวา ไม่บังการคลิกแต่บังสายตา
- แก้สคริปต์ตอน Play อยู่ทำให้ Unity โหลดโค้ดใหม่แล้วเกิด NullReferenceException ให้หยุด Play แล้วเริ่มใหม่ ไม่ใช่บั๊กของเกม

## งานที่เหลือ

1. วาดงานศิลป์ตาม `ART_SLOTS.md`
2. ทดสอบเล่นจริงแล้วปรับความเร็วเดินและตำแหน่งวัตถุ
3. แก้ป้าย [E] และข้อความแจ้งเตือนที่ทับ
4. Build .exe สำหรับส่งประกวด
