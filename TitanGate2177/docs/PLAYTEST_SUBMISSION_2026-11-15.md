## เกมปัจจุบันคืออะไร

ชื่อที่แสดงบนเมนูคือ **LAST DOCK** อยู่ในโปรเจกต์ TitanGate2177 เป็นเกมนักบินฝึกหัดเอาชีวิตรอดบนดาวอังคาร 7 วัน ฐานใช้ 3 Work Units ต่อวัน เดินและอ่านแผงไม่เสียหน่วยงาน งานที่ยืนยันใช้เวลาและอาจทำให้ปัญหาอื่นแย่ลง

ระบบปัจจุบันมีอาหาร ออกซิเจน แบตเตอรี่ อะไหล่ น้ำ CO2 ความร้อน สภาพเครื่อง การสึกหรอ การจัดโหลดไฟ การผลิต/ใช้น้ำและ O2 แผงโซลาร์กับฝุ่น เหตุรั่ว/เครื่องเสีย พายุ แอร์ล็อก/กู้ซาก รถสำรวจ วิทยุ/เสาสัญญาณ แผนมื้อเย็น ความหิว และการเซฟแบบ replay actions รองรับภาษาไทย/อังกฤษ

ตอนนี้เป็นผู้เล่นมนุษย์อยู่คนเดียวในฐาน สัตว์เลี้ยง/ลูกเรือเพิ่มเติมไม่ได้เป็นฟีเจอร์หลักที่ควรโฆษณาในฉบับส่งนี้ แม้จะยังมีโค้ดเส้นทางเก่าอยู่ในโปรเจกต์

**แผนหุ่นยนต์บุคคลที่หนึ่ง ขาวดำ 3 วัน และแต้มเดิน 10 AP ที่คุยกันก่อนหน้า ยังเป็นเอกสารออกแบบ** ไม่ใช่สิ่งที่รอบทดสอบนี้เล่น ห้ามนำภาพคอนเซปต์มาอ้างเป็นภาพเกมที่ทำเสร็จแล้ว

## ประเด็นที่ควรจัดการก่อนส่ง

1. **คัตซีนขึ้นพื้นดำพร้อมข้อความ:** โค้ดปัจจุบันเรียก `Resources.Load<VideoClip>("Cine/...")` แต่ตรวจไม่พบไฟล์ `.mp4` ภายใน Assets/Resources และภาพ `p01_intro.png`/`ld90_end.png` ยืนยันภาพพื้นดำพร้อมคำบรรยาย เมนูและภาพฐานยังแสดงตามปกติ จึงเป็นปัญหา asset ของคัตซีน ไม่ใช่ข้ออ้างว่า screenshot ทั้งหมดดำเพราะรัน background ให้ทีมที่กำลังทำคัตซีนใส่คลิปให้ครบหรือทำ fallback ก่อนถ่ายเดโม ไม่เปลี่ยนงาน render ของเพื่อนในรอบตรวจนี้
2. **ลิงก์โครงการยังไม่ยืนยันว่า public:** remote คือ `https://github.com/kittiphatrl-create/NASA` แต่การเปิดแบบไม่ล็อกอินตอบ 404 อาจเป็น private หรือปัญหาลิงก์ ห้ามใช้เป็นลิงก์ส่งจนลองเปิดแบบไม่ล็อกอินได้จริง
3. **ยังไม่มีเดโมสาธารณะที่ยืนยันในรอบนี้:** ตามไฟล์แบบฟอร์มที่ผู้ใช้แนบ ต้องมีวิดีโอไม่เกิน 30 วินาที หรือสไลด์ไม่เกิน 7 หน้า พร้อมลิงก์สาธารณะ เอกสารนี้ให้บทเดโม แต่ไม่ได้สร้าง/เผยแพร่เดโมแทน
4. **เครดิต/AI disclosure:** ต้องเช็กหมวด SI ที่ใช้จริง ลายน้ำภาพ/วิดีโอที่เข้าข่าย และ metadata โค้ด/ข้อมูลตามแบบฟอร์ม อย่าอ้างว่าทำครบแล้วเพราะมีคำอธิบายในช่องเดียว
5. **เสียงประตู:** docs/AUDIO_CREDITS.md ระบุไฟล์จากผู้ใช้/Pixabay และยังรอตรวจสิทธิ์ ข้อความต้นไฟล์ว่า audio ทั้งหมดเป็น CC0 ใช้ยืนยันสิทธิ์เสียงนี้ไม่ได้
6. **ความเหมาะสมกับเด็ก:** หน้าแผนสถานีและคำอธิบายบางหน้ามีข้อความมาก ควรให้เด็กอ่านจริงและทดสอบว่าหาค่าเวลา/ไฟ/เหตุฉุกเฉินเจอหรือไม่ การผ่านของบอตไม่ใช่หลักฐานว่าเด็ก 7–12 เล่นเข้าใจหรือเกมสนุกแล้ว

## NASA ใช้จริงอย่างไร

ใช้ NASA resources เป็นฐานความรู้และออกแบบสถานการณ์แบบ offline: ECLSS สำหรับ CO2/อิเล็กโทรลิซิส/น้ำ, ATCS สำหรับระบบระบายความร้อน, ISS power สำหรับโซลาร์และแบต, เหตุรั่ว ISS, Apollo 13 absorber และรายงานพายุที่ดาวอังคาร มีคำอธิบายวิทยาศาสตร์ในโค้ดและ docs/LAST_DOCK_SCIENCE_NOTES.md

ระบบออกซิเจนในฉบับนี้อธิบายการแยกน้ำ ไม่ใช่ MOXIE ที่แยก CO2 ดังนั้นข้อความส่งใหม่ต้องอิง ECLSS ไม่ใช่คัดคำบรรยายเวอร์ชันเก่าที่อ้าง MOXIE หรือ live DONKI API ไม่มีหลักฐานรอบนี้ว่าเกมเรียก NASA API สด

ตัวเลขหลอด หน่วยงาน สุขภาพ ความน่าจะเป็น และ 7 วันเป็น game balance ไม่ใช่ค่ามาตรฐาน NASA รายละเอียดแหล่งและ Link Text/URL เตรียมไว้ในไฟล์ submission ภาษาอังกฤษ
