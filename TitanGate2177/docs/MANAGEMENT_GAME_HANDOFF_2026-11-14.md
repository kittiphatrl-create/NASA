## 4. แกนของเกม: ไฟฟ้าคือทุกอย่าง

**หลอดหลักบนจอมี 3 หลอดเท่านั้น: ⚡ ไฟฟ้า · O₂ · อาหาร**

| หลอด | ใช้ไปกับ | ถ้าหมด |
|---|---|---|
| ⚡ ไฟฟ้า | **ทุกอย่างในฐานใช้ไฟ**: เครื่องผลิต O₂, ไฟส่องสว่าง, ฮีตเตอร์, วิทยุ, ชาร์จรถ, โล่กันรังสี | ฐานมืด → สิ่งแปลกปลอมเข้าใกล้ (ข้อ 9) |
| O₂ | ทุกคนหายใจทุกคืน; ได้จากเครื่องผลิต O₂ (กินไฟ) หรือถัง O₂ | แพ้ |
| อาหาร | กินทุกคืน; ได้จากของที่เก็บมาและการสำรวจ | หิว → สุขภาพลด → แพ้ |

ปัญหาตั้งต้น: **ไฟที่มีไม่พอใช้ถึงวันที่ 7** ผู้เล่นต้องออกหาทรัพยากร หรือยอมปิดบางระบบ คำถามประจำวันของเกมคือ "วันนี้จะเอาไฟไปใช้กับอะไร"

สุขภาพของตัวผู้เล่นเป็นค่าเสริม (หัวใจ 3 ดวง) ลดจากหิว รังสี อาหารเสีย รักษาด้วยยา

## 5. ของจากยาน (วิ่งเก็บ 60 วินาที)

ของที่เก็บมาตอนวิ่ง 60 วินาทีต้องสำคัญต่อการเล่นในฐาน แบ่งเป็น 2 กลุ่ม:

### 5.1 ของสำคัญ — ไม่สุ่ม · อยู่ในกล่องล็อก · ได้แค่ชิ้นเดียวต่อเกม

ของสำคัญแต่ละชิ้นอยู่ใน **กล่องที่ล็อกไว้** (เป็นกล่อง ไม่ใช่ห้อง) **กล่องทั้ง 3 ใบอยู่บนยาน** ตอนวิ่งเก็บของ 60 วินาที ผู้เล่นหยิบกล่องลงยานชูชีพได้เหมือนของอื่น **กล่องละ 1 ช่อง** (แย่งช่องกับถัง O₂ อาหาร แบตเตอรี่)

ลงถึงฐานแล้ว ผู้เล่น **ได้คีย์การ์ด 1 ใบจากการทำเควสวันที่ 1** คีย์การ์ดปลดล็อกได้ **กล่องเดียวต่อเกม** จึงได้ของสำคัญแค่ 1 ชิ้น ถ้าหยิบกล่องมาหลายใบ ใบที่เหลือเปิดไม่ได้ เสียช่องเปล่า ๆ — การเลือกหยิบกล่องไหนตอนวิ่ง 60 วินาทีจึงเป็นการตัดสินใจสำคัญ

| ของสำคัญ | ผลในฐาน |
|---|---|
| แผงโซลาร์พกพา | ไฟ +1 ทุกวัน (เกมง่ายขึ้นมาก) |
| ชุดซ่อมวิทยุ | เควสแรก "ซ่อมสัญญาณ" ใช้ 1 วันแทน 3 วัน |
| กล่องอาหารแช่แข็ง | อาหารปลอดภัย ไม่ต้องเสี่ยงอาหารสุ่ม (ข้อ 7) |

- คีย์การ์ดได้จากเควสวันที่ 1 (เควสสอนเล่นในฐาน) ใช้ครั้งเดียว เปิดกล่องแล้วกล่องอื่นเปิดไม่ได้อีก
- กล่องบนยานควรมีป้ายบอกว่ามีอะไรข้างใน และบอกตั้งแต่บนยานว่า "ต้องมีคีย์การ์ดถึงจะเปิดได้ เปิดได้แค่ใบเดียว" เพื่อให้เป็นการเลือกที่รู้ตัว
- ไม่ได้หยิบกล่องเลยก็ได้ (ได้ช่องไปใส่ของอื่นแทน) — คีย์การ์ดจะไม่มีประโยชน์

### 5.2 ของไม่สำคัญ — สุ่มตำแหน่ง/สุ่มว่ามีในรอบนี้หรือไม่

| ของ | ผล |
|---|---|
| เครื่องวัดรังสี | ออกสำรวจแล้วรู้ล่วงหน้าว่าจุดไหนรังสีสูง |
| ปืนไล่ / ไฟฉาย | ไล่สิ่งแปลกปลอม หรือเอาไปแลกกับผู้มาเยือน |
| ยารักษา | สุขภาพ +1 (หายป่วยจากอาหารเสีย/รังสี) |
| ถัง O₂ / แบตเตอรี่ / อาหาร / น้ำ | เติมหลอดตรง ๆ (มีอยู่แล้วใน config: `sup_o2`, `sup_battery`, `sup_food`, `sup_water`) |
| อื่น ๆ | เพิ่มได้ตามสมดุล |

ยานชูชีพจุของได้จำกัด (ตอนนี้ `chapter1.stowSlots = 5`, ถือได้ทีละ 3 ชิ้น `HandSlots = 3`)

## 6. หนึ่งวันในฐาน (สั้น ~2 นาที)

1. **เช้า:** ORBI รายงานสั้น ๆ — หลอดทั้ง 3, พยากรณ์ (มีพายุไหม), เหตุการณ์ของวัน
2. **กลางวัน:** เลือกการกระทำ 2–3 อย่าง (ข้อ 7)
3. **เย็น:** แบ่งอาหาร + เลือกว่าคืนนี้จะเปิดอะไรทิ้งไว้ (เครื่องผลิต O₂ / ฮีตเตอร์ / ไฟส่องทางเข้า / โล่กันรังสี) — ทั้งหมดกินไฟ
4. **กลางคืน:** สรุปผลเป็นข้อความสั้น + ภาพ เช่น "ไฟดับตอนตี 3 มีเสียงขูดที่ประตู..."

7 วัน × ~2 นาที ≈ 15 นาที

## 7. การกระทำตอนกลางวัน

### ออกไปสำรวจข้างนอก (หัวใจความตื่นเต้น)
- กดออกไป → **จอตัดดำ** ("คุณเดินออกไป...") → ตัวละครเดินกลับเข้ามา พร้อมผลแบบสุ่ม
- ผลที่เป็นไปได้: เจออะไหล่ / อาหาร / ถัง O₂ / **ชิ้นส่วนรถ** (ข้อ 8) / ติดรังสี (สุขภาพลด) / ชุดรั่ว (เสีย O₂) / หลงทาง (เสียเวลา) / สัญญาณประหลาด
- **เมื่อกลับมาถึงบ้าน มีโอกาสเจออะไรบางอย่างในฐาน** ระหว่างที่เราไม่อยู่ เช่น ของหาย, มีคนแอบเข้ามา, เครื่องเสีย, หรือมีแขกรออยู่หน้าประตู
- เครื่องวัดรังสีช่วยลดความเสี่ยงเรื่องรังสี
- ใช้ได้วันละ 1–2 ครั้ง

### อาหารอวกาศแบบสุ่ม (gambling)
- อาหารที่ได้จากการสำรวจเป็นกล่องเก่าไม่มีฉลาก: กินแล้วสุ่ม **ปกติ / ดีมาก (อิ่ม+มีความสุข) / เสีย (ปวดท้อง สุขภาพ −1)**
- กล่องอาหารแช่แข็ง (ของสำคัญ) = กินได้ปลอดภัย
- ยารักษาแก้อาการอาหารเสีย
- ข้อมูลจริงรองรับ: อาหารอวกาศมีอายุการเก็บ บรรจุภัณฑ์ที่เสียหายทำให้อาหารเสียได้

### อื่น ๆ
- **ซ่อม/อัปเกรดฐาน** (ใช้อะไหล่): แผงโซลาร์เพิ่ม, แบตเตอรี่ใหญ่ขึ้น, ประตูแน่นขึ้น
- **ซ่อมสัญญาณสื่อสาร** (เควส 1)
- **พัก** (ไม่เสียของ แต่เสียเวลา)
- **ส่งรถไปสำรวจ** (หลังได้รถ)

## 8. รถสำรวจ — รางวัลกลางเกมที่ต้องแลกหนัก

1. ต้องเก็บ **ชิ้นส่วนรถให้ครบทุกชิ้นก่อน** (ได้จากการสำรวจข้างนอก)
2. ประกอบรถ
3. ใช้รถได้ต้อง **ชาร์จไฟจำนวนมหาศาล** (กดดันเรื่องไฟ)
4. **ผู้เล่นเลือกอัปเกรดรถเอง** โดยเอาของจากฐานไปใส่รถ แต่ละอย่างทำให้รถดีขึ้นแต่ฐานเสียของนั้นไป เช่น
   - ใส่แผงโซลาร์ที่รถ → รถชาร์จตัวเองได้ ไม่ต้องใช้ไฟฐาน แต่ฐานได้ไฟต่อวันลดลง
   - ไม่ใส่ → รถกินไฟฐานทุกครั้งที่ออก
   - อัปเกรดอื่น ๆ (ผู้สร้างคิดเพิ่มได้): ใส่แบตเตอรี่สำรอง (ไปไกลขึ้น เจอของมากขึ้น แต่คืนพายุฐานเสี่ยงขึ้น), ใส่เครื่องวัดรังสี (เลี่ยงจุดรังสีสูง)
5. ส่งรถออกไปตอนเช้า → กลับตอนเย็น ได้ของมากกว่าเดินเองมาก แต่สุ่มเหตุการณ์:
   - รถพัง ต้องใช้ไฟ/อะไหล่ซ่อม
   - **มีโจรตามรถกลับมา** → ผู้เล่นเลือก: ยอมให้อาหาร / ให้ไฟ / ให้ของอื่น / ปฏิเสธ (เสี่ยงโดนปล้นตอนกลางคืน) — เป็นเหตุการณ์ข้อความ+ตัวเลือก ไม่ใช้ระบบตาแมว

## 9. ภัยและเหตุการณ์

- **ไฟไม่พอ = สิ่งแปลกปลอมมา:** คืนที่ไฟหมดหรือปิดไฟส่องทางเข้า จะมีเสียงเคาะ/เงาที่หน้าต่าง ยิ่งมืดหลายคืนยิ่งเข้ามาใกล้ ถ้าเข้ามาถึงจะขโมยหรือทำของพัง ไล่ได้ด้วยปืนไล่/ไฟฉาย หรือยอมเปิดไฟ (ต้องบอกในเกมว่าเป็นเรื่องแต่ง)
- **พายุสุริยะ:** ORBI เตือนล่วงหน้า 1 วัน ต้องเลือกเก็บไฟไว้เปิดโล่กันรังสีคืนนั้น หรือเสี่ยง (ข้อมูลจริง: พายุสุริยะเพิ่มรังสีบนพื้นดาวอังคารและทำอุปกรณ์อิเล็กทรอนิกส์เสียหาย; ไม่ทำให้เกิดความร้อนหรือไฟไหม้)
- **เหตุการณ์สุ่มจากการสำรวจ** (ข้อ 7)
- ไม่มีระบบผู้มาเยือนเคาะประตูและตาแมว (ตัดออกแล้ว) — คนแปลกหน้ามาได้แค่ในเหตุการณ์รถ (โจร) และเหตุการณ์ตอนกลับจากสำรวจ

## 10. เควส

1. **เควส 1 — ซ่อมสัญญาณสื่อสาร:** ใช้ 3 วัน (หรือ 1 วันถ้ามีชุดซ่อมวิทยุ) ต้องใช้อะไหล่จากการสำรวจ เสร็จแล้ว ORBI ติดต่อโลกได้ว่ายานกู้ภัยจะมาวันที่ 7
2. **เควส 2 — อยู่รอด 7 วัน:** ไฟตั้งต้นไม่พอถึงวันที่ 7 ต้องหาทรัพยากรหรือเลือกปิดระบบ

แพ้: O₂ หมด หรือสุขภาพหมด → หน้าแพ้บอกสาเหตุ + เคล็ดลับ + เล่นใหม่

## 11. สิ่งที่ตัดออกแล้ว (ห้ามใส่กลับโดยไม่ถาม)

- **ระบบสัตว์เลี้ยงทั้งหมด** (เลือกสัตว์ก่อนวิ่ง, สัตว์เดินตาม, ความสามารถของสัตว์) — ผู้ใช้สั่งตัด
- **ผู้มาเยือนเคาะประตู + ตาแมว + สแกน + คุยกับผู้มาเยือน** — ผู้ใช้สั่งตัด
- ดาวเคราะห์ดวงอื่น, สถานีอวกาศ, เอเลียนหลายสายพันธุ์ — มากเกินไปสำหรับ 15 นาที

## 14. เกณฑ์ว่าเสร็จ

- เล่นจบได้ใน 15–20 นาที (วัดกับคนจริงอย่างน้อย 2–3 คน)
- บนจอมีหลอดหลักแค่ ⚡ / O₂ / อาหาร
- เควสวันที่ 1 ให้คีย์การ์ด → ปลดล็อกกล่องได้ใบเดียว ได้ของสำคัญ 1 ชิ้น และของชิ้นนั้นเปลี่ยนวิธีเล่นจริง
- ออกสำรวจ: จอตัด → กลับมาพร้อมผลสุ่ม และบางครั้งเจอเหตุการณ์ในฐาน
- รถ: ต้องเก็บชิ้นส่วนครบ + ชาร์จไฟมหาศาล + ผู้เล่นเลือกอัปเกรด (เช่น ย้ายแผงโซลาร์ไปใส่รถหรือไม่); ส่งรถแล้วมีเหตุการณ์สุ่ม (พัง/โจร) ให้เลือกตอบ
- ไฟไม่พอ → สิ่งแปลกปลอมเข้าใกล้ (มีคำเตือนก่อน)
- พายุสุริยะเตือนล่วงหน้า 1 วัน
- ไม่มีระบบสัตว์เลี้ยง ผู้มาเยือน และตาแมวเหลืออยู่
- บอทเล่นรอบคอบรอดได้ส่วนใหญ่ (≥4/5 seed) บอทเล่นมักง่ายแพ้ทุกรอบ
- EditMode tests ผ่านทั้งหมด

## 15. คำตอบจากผู้ใช้ (ไม่ต้องถามซ้ำ)

- ในฐาน **ผู้เล่นเดินตัวละครไปกดเองในแผนที่** (เดินไปประตูเพื่อออกสำรวจ, เดินไปโรงรถเพื่อส่งรถ, เดินไปเครื่องผลิต O₂ เพื่อเปิด ฯลฯ) ไม่ใช่เมนูแบบ 60 Seconds; ใช้แผนที่ฐานและระบบเดินที่มีอยู่ (`GameFlow.Base.cs`, ตอนนี้อยู่ในโหมด walk-only)

- รถ: ชิ้นส่วนที่หามาประกอบได้เลย, ชาร์จต้องใช้ไฟมหาศาล, ผู้เล่นเลือกอัปเกรดเอง (เช่น ย้ายแผงโซลาร์ไปใส่รถหรือไม่)
