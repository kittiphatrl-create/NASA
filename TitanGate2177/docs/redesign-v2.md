ภาพอ้างอิง: `F:\NASA\docs\ref_survival_base.jpg` (ภาพจาก Steam ใช้อ้างอิงเท่านั้น ห้ามใช้ในเกม)
คลิปที่เจ้าของโปรเจกต์ส่งมา ทั้งสองคลิปเป็นเกม **60 Parsecs!** (Robot Gentleman)

## กติกาเรื่องการลอกเกม

ยืม **แนวเกมและกลไก** ได้: วิ่งเก็บของจับเวลา มุมมองบน 3/4 การเอาชีวิตรอดเป็นวัน และมีแขกมาเคาะประตู
ห้ามเอา **ชื่อ ตัวละคร ลายเส้น แผนที่ เหตุการณ์ หรือข้อความ** ของ 60 Parsecs! มาใช้
เกมเราใช้เนื้อเรื่อง ตัวละคร (ORBI, โคเมท) ยาน Kestrel ดาวอังคาร และความรู้ NASA ของเราเอง
ส่วนที่เราต่างจาก 60 Parsecs! คือ: ช่วงเอาชีวิตรอดเราให้ **เดินจริงในฐาน** ไม่ได้อ่านไดอารีแล้วกดเลือกอย่างเดียว

## ปัญหาของเวอร์ชันตอนนี้

| ปัญหา | แก้ด้วย |
|---|---|
| ช่วงเอาชีวิตรอดเป็นการอ่านการ์ดแล้วกดปุ่ม ตัวละครไม่ได้ทำอะไร | เดินในฐานแล้วลงมือเอง: ปลูกผัก ให้อาหารสัตว์ ส่องตาแมว ซ่อมแผงโซลาร์ |
| เสียงเคาะประตูเป็นแค่กล่องข้อความ | เดินไปที่ประตู ส่องตาแมวเห็นตัวแขก แล้วคุยกันเอง |
| ช่วงแรกยาวและเป็นแค่ซ่อมไปเรื่อยๆ | ย่อเหลือเควสสอนเล่นสั้นๆ 3–4 นาที แล้วตัดเข้าอุบัติเหตุเลย |
| มุมกล้องด้านข้าง 2D | เปลี่ยนเป็นมุมบน 3/4 แบบในคลิป |

## โครงเกมใหม่ (ประมาณ 25–35 นาที)

```
[องก์ 0] เช้าบนยาน Kestrel (3–4 นาที, ไม่มีทางแพ้)
   ORBI ให้เควสสั้น 4 อัน วิ่งไปทั่วยาน → สอนเดิน / หยิบ / ถือ / ใช้ / ให้ของ
   → นั่งพักที่ห้องนั่งเล่น → คัตซีน: อุกกาบาตชน ยานสั่น ไฟแดง สัญญาณเตือน
[องก์ 1] วิ่งเก็บของ 60 วินาที (เวลาจริง)
   วิ่งทั่วยานเก็บน้ำ อาหาร ของใช้ เมล็ดพันธุ์ สัตว์เลี้ยง ใส่ยานชูชีพ ถือได้ครั้งละ 4 ชิ้น
   → หมดเวลา: คัตซีนยานชูชีพหลุดออก → ลงจอดดาวอังคาร → ต่อเข้ากับฐานร้างบนดาวอังคาร
[องก์ 2] ฐานบนดาวอังคาร 7 วัน
   ของที่เก็บมาจากองก์ 1 อยู่บนชั้นวางในคลัง
   ทุกวัน: กลางวันเดินทำงานในฐาน → มีเหตุการณ์ (เคาะประตู ไฟดับ พายุฝุ่น)
   → ตกค่ำแบ่งอาหาร/น้ำ → นอน → เช้าวันใหม่
   วันที่ 7: ยานกู้ภัยมาถึง ถ้าส่งพิกัดได้ = รอด
```

### องก์ 0 — เควสสอนเล่น (แทนปริศนาบทที่ 1 เดิม)

แต่ละเควสสอนการกระทำเดียว และเป็นเควสที่ทำให้ผู้เล่นรู้ว่าของในยานอยู่ตรงไหน ผู้เล่นจะได้ใช้ความรู้นี้ตอนวิ่งเก็บของ 60 วินาที

| เควส | สอน | ได้การ์ดความรู้ |
|---|---|---|
| ให้อาหารสัตว์เลี้ยงในห้องพัก | เดิน + ใช้ของ | อาหารในอวกาศ |
| เอาไส้กรองน้ำจากคลังไปเปลี่ยนในห้องรีไซเคิล | หยิบ + ถือ + ใช้กับเครื่อง | ระบบรีไซเคิลน้ำบน ISS |
| รดน้ำต้นผักในห้องทดลอง | ใช้ของกับของ | VEGGIE บน ISS |
| ส่งกาแฟให้ผู้บังคับการในห้องบังคับ | ให้ของกับคน | การหน่วงเวลาสื่อสาร |

ตัดออกจากของเดิม: เลือกเส้นทางจากเกจเชื้อเพลิง และเรียงขั้นตอนลงจอด (EDL) ให้ย้ายไปเป็นคัตซีน + การ์ดความรู้
ยังเก็บเส้นทางดาวอังคารไว้เส้นเดียวก่อน ส่วนดวงจันทร์/ไททันเก็บไว้ทำทีหลัง

### องก์ 1 — วิ่งเก็บของ 60 วินาที (ปรับของที่มีอยู่)

- มุมบน 3/4 เห็นยานทั้งลำในจอเดียว หรือกล้องเลื่อนตามตัวละคร
- ถือได้ 4 ช่อง วางของลงยานชูชีพได้ครั้งละหลายชิ้น
- ของ: น้ำ ×3, อาหารกระป๋อง ×3, ชุดปฐมพยาบาล, ชุดเครื่องมือ, วิทยุ, เมล็ดพันธุ์, ถังออกซิเจน, ไฟฉาย, ขนมสัตว์เลี้ยง
- ตำแหน่งของสุ่มเล็กน้อยทุกครั้ง แต่อยู่ในห้องที่เควสสอนไว้
- ภัยระหว่างวิ่ง: ไฟดับเป็นช่วง ประตูบางบานติดจากแรงชน ไฟลุกในห้องเครื่อง (ทางลัดที่เสี่ยง)

### องก์ 2 — ฐานบนดาวอังคาร (หัวใจของเกม)

ฐานมี 6 โมดูล ต่อกันด้วยทางเดิน เดินไปมาได้ด้วยมุมกล้องแบบเดียวกับองก์ 1

```
            [แผงโซลาร์/ข้างนอก]
                   |
[เรือนกระจก] — [ห้องพัก/ครัว] — [ประตูปรับแรงดัน (ตาแมว)]
                   |
[คลังเสบียง] — [ห้องเครื่อง/ไฟฟ้า] — [ห้องสื่อสาร (บีคอน)]
```

| โมดูล | สิ่งที่ทำ (ผู้เล่นทำเอง) |
|---|---|
| ห้องพัก/ครัว | ดูแลลูกเรือ (หิว กระหาย สุขภาพ อารมณ์) นอน จบวัน แบ่งอาหารตอนค่ำ |
| เรือนกระจก | ปลูกผัก (มันฝรั่ง ผักกาด) ใช้น้ำ + ไฟ โตใน 2–3 วัน เก็บมาแทนอาหารกระป๋องได้ |
| คลังเสบียง | เห็นของเป็นชิ้นบนชั้น นับได้ด้วยตา ไม่ต้องดูตัวเลข |
| ห้องเครื่อง | ซ่อมไฟ เปิด-ปิดระบบ (ใช้ OutpostSim เดิม) |
| ข้างนอก | ใส่ชุดอวกาศ ปัดฝุ่นแผงโซลาร์ เก็บน้ำแข็ง หาของ |
| ห้องสื่อสาร | ซ่อมบีคอน ส่งพิกัดให้ยานกู้ภัย (เงื่อนไขชนะ) |
| ประตูปรับแรงดัน | แขกมาเคาะ (ดูด้านล่าง) |

**สัตว์เลี้ยง:** เลือก 1 ตัวก่อนวิ่งเก็บของ (มีอยู่แล้ว) ต้องให้อาหาร เล่นด้วย มันช่วยได้ เช่น ดมหาของ หรือเตือนเมื่อแขกอันตราย

**เวลา:** กลางวันหนึ่งวันเดินเล่นจริงประมาณ 3 นาที นาฬิกาเดินตามเวลาจริง การกระทำใหญ่ (ปลูก ซ่อม ออกไปข้างนอก) จะข้ามเวลาไปข้างหน้า ช่วงค่ำหยุดนาฬิกาเพื่อแบ่งอาหาร

### ฉากเคาะประตู + ตาแมว

1. มีเสียงเคาะ 3 ครั้ง ไอคอน `!` ขึ้นที่ประตู และ ORBI พูดว่า "มีคนอยู่หน้าประตู"
2. ผู้เล่นเดินไปที่ประตู (เดินไปเองได้หรือไม่สนใจก็ได้ ถ้าไม่ไปภายในชั่วโมงในเกม แขกจะไปเอง)
3. คลิกตาแมว: ตัดเข้าภาพมองลอด เป็นวงกลมเลนส์ตาปลา ขอบมืด เห็นแขกยืนอยู่ข้างนอก มีฝุ่นปลิว
4. เครื่องมือตรวจ (ใช้ระบบสแกนเดิม จำนวนครั้งจำกัด): กล้องอินฟราเรด เซ็นเซอร์ลมหายใจ ไมโครโฟนติดประตู แต่ละอันเปิดเผยรายละเอียดหนึ่งอย่างบนภาพ
5. คุยกัน: บทพูดสั้นๆ 2–3 รอบ คำตอบของเราเปลี่ยนท่าทีของแขก
6. ตัดสินใจ: รับเข้ามา (เดินเข้ามาอยู่ในฐานจริง กินเสบียงด้วย แต่ช่วยงานได้) / แลกของผ่านช่องประตู / ไม่เปิด

ผลที่ตามมาเห็นได้ในฐาน เช่น แขกที่รับเข้ามาเดินไปช่วยรดผักจริง หรือขโมยของจากคลังตอนกลางคืน

## มุมกล้องและภาพ

- **มุมบน 3/4 (top-down three-quarter):** กล้อง orthographic มองลงมาประมาณ 50–60° ไม่แสดงผนังหน้า แต่แสดงผนังหลังเป็นแถบสูง ห้องจึงดูเหมือนบ้านตุ๊กตาที่มองจากด้านบน
- **เรียงลำดับวาดตามแกน Y:** ตั้ง `Graphics Settings → Transparency Sort Axis = (0, 1, 0)` ให้ของที่อยู่ล่างจอวาดทับของที่อยู่บน ตัวละครจึงเดินอ้อมหลังโต๊ะได้
- **ภาพ:** ใช้ pixel art ที่สร้างด้วยโค้ดเหมือนเดิม (`PixelCanvas`) แล้วค่อยแทนด้วย sprite ที่วาดมือ ใช้ขนาดพิกเซลเดียวกันทั้งเกม (เช่น 1 พิกเซลศิลป์ = 3 พิกเซลจอ ที่ 1080p)
- **พื้นเป็นกริด:** ฐานวางบนตารางช่อง ทำให้เดินอ้อมของ (A*) ง่าย และเพื่อนวาด tile ได้ทีละชิ้น

## แสง

โปรเจกต์ตอนนี้ใช้ built-in renderer ซึ่งไม่มีแสง 2D ในตัว มีสองทาง:

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **A. แสงปลอม (แนะนำ)** ใช้ชั้นมืดคูณทับทั้งจอ แล้วเจาะเป็นวงแสงจาก sprite แบบ additive | ไม่ต้องเปลี่ยนระบบ render ปลอดภัย เร็ว ใช้ได้กับ WebGL | ไม่มีเงาจริง |
| B. เปลี่ยนเป็น URP 2D + `Light2D` | แสงจริง มีเงา มี normal map | ต้องเปลี่ยน render pipeline ทั้งโปรเจกต์ ต้องแปลง material ทุกอัน เสี่ยงงานพัง |

แผนแสงทาง A:
- **ยานตอนเช้า (องก์ 0):** สว่าง โทนอุ่น ฟ้า-ขาว
- **ตอนชน (องก์ 1):** ชั้นมืด 50% ไฟฉุกเฉินสีแดงหมุนวน ประกายไฟ ไฟดับเป็นช่วงแล้วเหลือแค่วงแสงรอบตัวละคร
- **ฐานดาวอังคารกลางวัน:** แสงสีส้มอ่อนลอดหน้าต่าง
- **กลางคืน:** มืด 70% เหลือแสงจากจอคอมพิวเตอร์ หลอดไฟเรือนกระจกสีม่วงชมพู (หลอด LED ปลูกพืชแบบ VEGGIE ใช้แสงแดง+น้ำเงิน) และไฟฉาย
- **ไฟฟ้าต่ำ:** ไฟในห้องกะพริบและหรี่ตามระดับไฟฟ้าใน OutpostSim ผู้เล่นจึงเห็นปัญหาได้ด้วยตา
- **พายุฝุ่น:** ฉากข้างนอกเป็นหมอกสีน้ำตาล แสงในฐานหรี่

## ระบบเดิมที่ใช้ต่อได้

| ของเดิม | ใช้ต่อเป็น |
|---|---|
| `OutpostSim` (ไฟฟ้า โซลาร์ พายุ บีคอน กู้ภัย) | ระบบไฟฟ้า/ข้างนอก/ห้องสื่อสารขององก์ 2 |
| `LifeboatSim` (แขก สัตว์เลี้ยง แบ่งอาหาร คืนนี้เกิดอะไร) | ใช้กฎเดิม เปลี่ยนแค่วิธีเล่นจากกดการ์ดเป็นเดินไปทำเอง |
| ฉากวิ่งเก็บของ 60 วินาที (`GameFlow.Scramble`) | เปลี่ยนเป็นมุมบน 3/4 ทั่วยาน |
| คัตซีน (`GameFlow.Cutscenes`) | อุกกาบาตชน หนีออกจากยาน ลงจอด ต่อเข้าฐาน |
| การ์ดความรู้, ORBI hint, ภาษาไทย/อังกฤษ, `config.json`, test | ใช้ต่อทั้งหมด |

ต้องทำใหม่: กล้องและการเดินแบบบน 3/4, แผนที่ยานและฐานเป็นกริด, เควสองก์ 0, ฉากตาแมว, เรือนกระจก, แสงปลอม

## ลำดับการทำ (แต่ละขั้นเล่นได้จบในตัว)

1. กล้องบน 3/4 + เดินบนกริด + เรียงลำดับการวาด ในยานห้องเดียว
2. แผนที่ยานทั้งลำ + เควสองก์ 0 + คัตซีนอุกกาบาต
3. วิ่งเก็บของ 60 วินาทีบนแผนที่ใหม่
4. ฐานดาวอังคาร 6 โมดูล + วันกลางวัน/กลางคืน + แบ่งอาหาร
5. ฉากเคาะประตูและตาแมว
6. เรือนกระจก + สัตว์เลี้ยง + แขกที่อยู่ในฐาน
7. แสงปลอม + เสียง + ปรับตัวเลข + ทดสอบเล่นทั้งเกม

## เรื่องที่ต้องตัดสินใจ

1. แสง: ทาง A (แสงปลอม) หรือทาง B (URP 2D) — แนะนำ A
2. เวลากลางวัน: เดินตามเวลาจริง (แนะนำ) หรือแบ่งเป็นแต้มการกระทำ
3. ทำในโปรเจกต์ `TitanGate2177` ต่อ (แนะนำ เพราะใช้ระบบเดิมได้) หรือเริ่มโปรเจกต์ใหม่
