บทที่ 2 ยาว 7 วัน มีรังสี (mSv) งานวิทยาศาสตร์ ทางเลือกยามเช้า และหน้าสรุปภารกิจ 3 ดาว · การ์ดความรู้ 40 ใบ ·

**ภาพ:** รอบ 5 ทำ "ปรับภาพให้เป็นชุดเดียวกัน" ด้วยโค้ดแล้ว (แสงทิศเดียว, ลายผิวจัดวางแทนจุดสุ่ม, ขนาดพิกเซลพื้นเท่ากับสิ่งของ,

## ขั้นที่ 1 — ขัดเกลา slice (สัปดาห์ที่ 1)

- **ภาพ (owner ขอไว้):** วาด sprite ด้วยมือใน Aseprite แทนภาพที่สร้างด้วยโค้ด เริ่มจากตัวละคร ORBI และเครื่องหลักแต่ละห้อง
  เปลี่ยนได้ทีละไฟล์ใน `Art.cs` โดยไม่ต้องแก้ระบบเกม

- **Save/Load** ระหว่าง sol (JSON ใน `Application.persistentDataPath`) — เกมสั้นแต่เด็กอาจปิดกลางทาง
- **ระดับความยาก** 3 ระดับ (Cadet / Pilot / Commander) = ชุดตัวเลขใน config 3 ชุด
- **ภาพ:** แอนิเมชันเปิดประตู, ฝุ่นพายุบนพื้นผิวตามพยากรณ์, แผงโซลาร์สกปรกค่อยๆ เปลี่ยน, ไฟห้องตามระดับไฟฟ้า
- **เสียง:** เพลงประกอบแบบ ambient 1–2 เพลง (ตอนนี้มีแค่ SFX สังเคราะห์)
- **การเข้าถึง:** ปรับขนาดตัวอักษร, โหมดตาบอดสี (สีแถบทรัพยากร), ปุ่มลัดทุกอย่างกดด้วยคีย์บอร์ดได้

## ขั้นที่ 2 — เนื้อหาเพิ่ม (สัปดาห์ที่ 2–3)

- **เรือนกระจก (Greenhouse):** ปลูกมันฝรั่ง ใช้น้ำ+ไฟ ได้อาหาร → ผูกระบบอาหารเข้ากับวงจรทรัพยากร + การ์ด "VEGGIE บน ISS"
- **เหตุการณ์ใหม่** (ทุกอันต้องเตือนล่วงหน้าและป้องกันได้): อุกกาบาตเล็ก, เครื่อง MOXIE ร้อนเกิน, ฝุ่นอุดตันตัวกรอง
- **ปริศนาข้ามห้องเพิ่ม** 2–3 ชุดต่อบท โดยคำตอบอยู่บนการ์ดความรู้เสมอ (ไม่มีการเดา)
- **การ์ดความรู้** เป็น 25+ ใบ, มีหน้า "สมุดนักบิน" สรุปสิ่งที่เรียนรู้ตอนจบ

## ขั้นที่ 3 — บทที่ 3: อีกฝั่งของประตูวาป (สัปดาห์ที่ 4–6)

(เส้นทางไททันในบทที่ 2 ไปถึงประตูแล้ว บทที่ 3 คือสิ่งที่รออยู่อีกฝั่ง และเส้นทางดาวอังคาร/ดวงจันทร์ต่อมาที่ไททันได้)

- ฉากบนไททัน: บรรยากาศไนโตรเจนหนา แรงโน้มถ่วงต่ำ ทะเลสาบมีเทน (ข้อมูลจาก Cassini-Huygens / Dragonfly)
- กลไกใหม่: บินด้วยโดรนแบบ Dragonfly สำรวจจุดต่างๆ เพื่อเก็บข้อมูลเปิดประตูวาป
- ปริศนาประตูวาป: ใช้ความรู้จากการ์ดทั้งเกม (เชื้อเพลิง, เดลต้า-วี, รังสี) มารวมกัน
- ตอนจบ: ผ่านประตูไปอีกกาแล็กซี (cliffhanger ไปภาคต่อ)

## ขั้นที่ 4 — การเผยแพร่

- Build เป็น **WebGL** (เล่นบนเบราว์เซอร์ได้ทันที เหมาะกับการส่งงาน/โรงเรียน) — ต้องทดสอบฟอนต์ไทยบน WebGL อีกครั้ง
- หน้า itch.io (คู่มือครูทำแล้ว) + เทียบการ์ดแต่ละใบกับหลักสูตรวิทยาศาสตร์ระดับชั้น
- เก็บสถิติแบบไม่ระบุตัวตน (ปริศนาไหนกด hint บ่อย) เพื่อปรับความยาก

## หลักที่ต้องรักษาไว้ในทุกขั้น

1. **คำตอบของปริศนาอยู่บนการ์ดความรู้เสมอ** — ไม่มีปริศนาที่ต้องเดา
2. **เหตุการณ์สุ่มต้องเตือนล่วงหน้าและป้องกันได้** — ความเสียหายหนักมีได้เฉพาะเหตุการณ์ใหญ่ที่เตือนตั้งแต่ต้น
3. **นักบิน 1 คน + AI 1 ตัว** — ไม่เพิ่มระบบลูกเรือหลายคน
4. **ทุกข้อความมีทั้ง TH และ EN** — test `Strings_EveryEntryHasBothLanguages` จะล้มถ้าลืม
5. **ตัวเลขเกมอยู่ใน config.json** — test `ShippedConfig_ReasonablePlanWins_ForManySeeds` ยืนยันว่าเกมยังชนะได้ทุกครั้งที่ปรับ
