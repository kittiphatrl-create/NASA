## งานค้างและความเสี่ยง

- ตรวจโคมว่าแนบผนังจริงและไม่ถูกผนังบัง ตรวจแสงพื้นและ falloff ในภาพสด
- ตรวจวัสดุผนังในทางเชื่อมและปรับหลังเห็นภาพจริง
- ตรวจ shimmer ระหว่างเดินและหมุน ยังไม่ได้ยืนยันสาเหตุหรือแก้ให้หาย
- PixelCanvas ใช้ Point filtering และกล้อง BCamera เคลื่อนแบบ Lerp จึงเป็นจุดตรวจเรื่อง subpixel sampling แต่ยังไม่ใช่ข้อสรุปสาเหตุ
- โคมใช้แถบกว้างแทนเส้นบาง ลดรายละเอียดความถี่สูงเฉพาะ asset ใหม่นี้
- F8 เรียก StartLastDock ซึ่งล้างเซฟเดิม ต้องใช้สภาพแวดล้อมทดสอบแยกข้อมูลเซฟก่อนตรวจ runtime
- หลังตรวจ pilot แล้ว งานต่อไปคือเครื่องเรือนและอุปกรณ์ Kestrel การแนบพื้น เงา ผนัง และความนิ่งของภาพทั้งสองแมพ
- การแก้รอบนี้ใช้ BSprite และ BLamp ไม่ได้เพิ่ม BProp หรือเปลี่ยน collision และพิกัด interaction
