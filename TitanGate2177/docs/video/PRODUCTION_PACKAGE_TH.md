## 1. แกนเรื่องและทิศทางภาพ

**แกนเรื่อง (1 ประโยค):** เพื่อนกลุ่มหนึ่งที่เริ่มจากห้อง Discord สร้างเกมเอาชีวิตรอดบนดาวอังคาร ที่ทำให้เด็กเข้าใจว่าฐานอวกาศอยู่รอดได้เพราะหลายระบบทำงานร่วมกัน

**สิ่งที่กรรมการควรจำหลังดูจบ**
1. LAST DOCK สอนระบบยังชีพ (อากาศ น้ำ ความร้อน ไฟฟ้า) ผ่านการตัดสินใจ ไม่ใช่การท่องจำ
2. ทุกปัญหาในเกมผูกกับแหล่งความรู้ NASA จริง (ECLSS, ระบบระบายความร้อน ISS, พลังงาน ISS, พายุสุริยะบนดาวอังคาร, Apollo 13)
3. ทีมสร้างเกมที่เล่นได้จริง มีระบบจำลองแยกจากภาพ มีเทสต์อัตโนมัติ และรองรับไทย/อังกฤษ

**ทิศทางภาพ**
- เปิด–ปิดด้วยหน้าจอ Discord (โทนมืด ม่วง/เทา) ตลกเบา ๆ เป็นกันเอง
- ช่วงกลางใช้ภาพเกมจริงเต็มจอ สลับสไลด์โทนเดียวกับ UI เกม: พื้นเขียวอมฟ้าเข้ม `#17302F` ตัวหนังสือครีม `#FFF2D6` เน้นสีฟ้าเขียว `#8AE0CF` ฟอนต์ Chakra Petch
- เพลง: ใช้เพลงในเกม (SRG774 Dark Sci-Fi, CC0) เบาลง −18 dB ใต้เสียงพูด
- ตัวหนังสือบนจอสูงอย่างน้อย 48 px ที่ 1080p เพื่อให้อ่านบนมือถือได้
